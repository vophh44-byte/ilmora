# Ilmora — The Journey of Knowledge

**Arabic:** رِحْلَةُ الْعِلْمِ  
**Tagline:** Learn. Explore. Grow.

Ilmora is planned as a browser-based learning adventure for Arabic, English, and carefully sourced Islamic knowledge. The project should grow in small, testable steps while preserving any working features and data.

## Current structure

- `index.html` — application entry page
- `css/style.css` — global styles
- `js/main.js` — JavaScript entry point
- `js/modules/` — future reusable feature modules
- `js/data/` — future structured lesson and curriculum data
- `assets/` — images and other static assets
- `assets/icons/` — project icons

## Run locally

Open `index.html` in a modern web browser. This starter page uses plain HTML, CSS, and JavaScript and does not require a package manager or build step.

## Development notes

The current page is only a starter shell, not the completed game. Add a feature only when its purpose and behaviour are clear; keep lessons and curriculum data separate from interface logic. Do not add credentials or private keys to this public repository.
